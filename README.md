# ZEITSPRUNG – KI-POV-Videos aus der Vergangenheit (und Zukunft)

Ein Kanal-Konzept für virale TikTok-KI-Videos.

**Die Nische in einem Satz:**
> "POV: Du wachst als ganz normaler Mensch in einer anderen Zeit auf" – realistische KI-Videos aus der Ich-Perspektive, die zeigen, wie sich ein Tag in der Vergangenheit (oder Zukunft) **wirklich** angefühlt hätte.

## Inhalt

| Datei | Wofür |
|---|---|
| [`NISCHE.md`](NISCHE.md) | Warum diese Nische viral geht, Zielgruppe, Kanal-Branding, Hooks, Posting-Plan |
| [`SKRIPTE.md`](SKRIPTE.md) | 10 fertige Videos: Hook, Szenen, KI-Prompts, Voiceover, Caption, Hashtags |
| [`WORKFLOW.md`](WORKFLOW.md) | Schritt für Schritt von der Idee zum fertigen TikTok (Tools, Schnitt, Sound) |

## Schnellstart

1. Kanalname und Bio aus `NISCHE.md` übernehmen.
2. Video #1 aus `SKRIPTE.md` nehmen, die Szenen-Prompts in deinen KI-Video-Generator kopieren.
3. Voiceover erzeugen, in CapCut zusammenschneiden (Anleitung in `WORKFLOW.md`).
4. Posten, Kommentare lesen, die meistgewünschte Epoche als nächstes machen.
